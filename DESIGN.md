# Estándar de diseño frontend

## Colores base
- Fondo general: `#f4f6f8`
- Tarjetas/superficies: `#ffffff`
- Borde de tarjeta/campos: `#d9dee5`
- Texto principal: `#1f2937`
- Texto secundario: `#6b7280`
- Acción primaria: `#2563eb`
- Error: `#b91c1c`

## Tipografía y espaciado
- Fuente principal: `Inter, system-ui, -apple-system, Segoe UI, sans-serif`
- Bordes redondeados:
  - Campos y botones: `8px`
  - Tarjetas: `12px`
- Sombras suaves para superficies elevadas.

## Componentes
- Formularios con etiquetas visibles sobre cada campo.
- Botón primario azul con texto blanco.
- Mensajes de error en rojo.
- Layout centrado para pantallas de autenticación.
